# Documentation

- `[documentation-001]` Do not add code comments by default. Add one only for a non-obvious constraint, a workaround or the reason for a surprising choice, in one or two lines. Never restate the code, narrate the change or cite a ticket or PR.
  - why: Narrating comments rot and add noise; the rare comment that survives is the one that explains why.
