# Failure modes seen so far

Each row is a thing that went wrong while building this, with the cause and the fix. Add rows when you meet a new one.

| Symptom                                                                                      | Cause                                                                                                    | Fix                                                                                                                                                                 |
| -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `403 EMAIL_VERIFICATION_REQUIRED_BEFORE_ACCEPTING_OR_REJECTING_INVITATION`                   | `generateId: false` makes Better Auth require a verified email for invitations; no mail transport exists | BLOCKED, cause environment. See [personas](personas.md). Do not bypass with SQL.                                                                                    |
| `provision.sh`: `cannot sign in as the super admin`                                          | The stack has no super admin with `E2E_SUPERADMIN_EMAIL`, or the password differs                        | A worktree stack creates it on `up`; on the shared stack run `nx run api:bootstrap-admin` with those credentials or export the seed's (`admin@eduvault.test`)       |
| `403 MustChangePassword` on every call of a persona                                          | The account is still on its temporary password                                                           | `POST /me/password` first; `provision.sh` does it for `owner` and `foreign`                                                                                         |
| `BLOCKED (environment): http://localhost:3000/health is not answering`                       | Stack not running                                                                                        | `run-local` recipe, `preflight.sh`, run again                                                                                                                       |
| `strict mode violation: getByLabel('Campus') resolved to 2 elements`                         | The Students page has a "Campus" field next to the campus switcher                                       | Scope to `page.getByRole('banner')`                                                                                                                                 |
| `403 You are not allowed to delete this team` on `DELETE /campuses/:id`                      | Seen when deleting a campus on its own as the owner                                                      | Delete the school; the campus goes with it                                                                                                                          |
| `playwright-cli: command not found`                                                          | The CLI is not installed                                                                                 | BLOCKED, cause environment; install it, then run again                                                                                                              |
| `403` or `INVALID_ORIGIN` from `curl`                                                        | The request had no `origin` header                                                                       | Send `-H "origin: $E2E_ADMIN_URL"`                                                                                                                                  |
| `cleanup.sh` prints `skip ...: sign-in 4xx`                                                  | It ran without the stack's `E2E_*_URL`, so it signed in on a different stack                             | `eval "$(bash .../stack-worktree.sh env <worktree>)"` first, then cleanup before `down`                                                                             |
| `stack-worktree.sh up` from the main checkout rebuilds `apps/api/dist`                       | It builds in the tree it is given                                                                        | Use a real worktree; do not point it at a checkout whose API is running                                                                                             |
| `preflight.sh` says `answers /health but is not Eduvault's API`                              | Another project's API owns that port and also answers `{"status":"ok"}`                                  | Start this worktree's stack (`stack-worktree.sh up`) and `eval` its `env`; never test against that port                                                             |
| `stack-worktree.sh up`: `port <n> is taken by <command> pid <pid>`                           | An earlier run's API or vite server survived, or another stack holds the port                            | `stack-worktree.sh down <worktree>` sweeps this worktree's strays; kill the named pid if it belongs to nobody                                                       |
| `stack-worktree.sh down`: `still running after down: pids ...`                               | A stack process escaped its recorded pid and survived the sweep                                          | Kill the named pids, then `down` again; never start a new stack over them                                                                                           |
| `stack-worktree.sh up` exits 3: `no free port triple found`                                  | Every triple from api :3710 to :3790 is in use                                                           | `stack-worktree.sh status`, `down` the stale ones                                                                                                                   |
| The run is green but the `e2e:` line names `:3700`, `:4700` or `stack=shared`                | The shell had the launcher's `E2E_*` URLs, so the run used its stack, not the worktree's                 | `eval "$(bash .../stack-worktree.sh env <worktree>)"`, rerun preflight, and redo the run; `verify.sh e2e` rejects a report that does not quote the worktree's ports |
| `db:seed` aborts on an existing user such as `multi@eduvault.test`, or leaves a partial seed | It ran against a database that already holds another seed                                                | Never seed from a run. Use a stack whose database has migrations only, and `provision.sh` for personas                                                              |
| A step "passes" although a `playwright-cli run-code` snippet threw                           | `run-code` and `eval` exit 0 on a thrown snippet                                                         | grep the output for `### Error`; see Assertions in the skill                                                                                                        |
| `get-session` step passes while signed out                                                   | It answers 200 with `null`                                                                               | Assert `user.id` in the body                                                                                                                                        |
